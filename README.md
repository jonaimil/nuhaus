# Nuhaus

Co-living for creative, technical, and cultural people in Tokyo.

## About

Interactive 3D landing page built with Three.js. Features a configurable modular building with animated residents.

## Local Development

Just open `index.html` in a browser, or run a local server:

```bash
npx serve .
```

## Tech

- Three.js (3D rendering)
- Lottie (walking animations)
- Tailwind CSS (styling)
- No build step — pure HTML/JS
